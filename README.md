# Atividade de Revisão - JavaScript Fundamentos 3 - Turma B - Miguel.

## Objetivo

Revisar e praticar os conteúdos estudados no módulo JavaScript Fundamentos 3, aplicados ao desenvolvimento Back-End.

Esta é a versão destinada à **Turma B**. A atividade possui **35 exercícios**, organizados em ordem de dificuldade e separados por conteúdo. Os exercícios trabalham os mesmos conceitos e possuem nível equivalente ao da outra turma, porém utilizam situações diferentes.

## Como realizar

Abra os exercícios seguindo a ordem numérica e escreva sua solução abaixo dos comentários presentes em cada arquivo.

Para executar um exercício:

```bash
node caminho-do-arquivo.js
```

Exemplo:

```bash
node 01-funcoes/01-calcular-comissao.js
```

## Orientações

- Não apague nem modifique os enunciados.
- Resolva os exercícios na ordem indicada.
- Teste cada arquivo utilizando Node.js pelo terminal.
- Utilize os conceitos solicitados em cada exercício.
- Mantenha o código organizado e utilize nomes de variáveis claros.
- Não copie códigos prontos.
- Faça commit e push das soluções no seu próprio repositório do GitHub.
- Em caso de erro, leia a mensagem exibida no terminal antes de pedir ajuda.

## Objetivo da revisão

Verificar a compreensão de funções, métodos de Arrays, objetos, recursos modernos, JSON e Programação Orientada a Objetos antes de avançar para módulos, programação assíncrona, Express.js, APIs REST e banco de dados.
